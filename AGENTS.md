# Правила работы в репозитории

Проект **locusfood.by** — сайт натуральных продуктов с доставкой в Витебске.
Стек: Vite + React + TypeScript + shadcn/ui (Tailwind).

## Git

- **В `main` не пушить напрямую.** Любая правка: ветка от `main` → коммит → pull request.
- Имена веток: `fix/<кратко>`, `feat/<кратко>`, `chore/<кратко>`.
- Один PR — одна задача. Сообщение коммита — по существу, на русском.
- Перед пушем посмотреть `git diff` и убедиться, что в изменения не попали лишние файлы
  (`node_modules`, `dist`, `.env`, локальные конфиги).
- В описании PR: что изменено, зачем, как проверено.

## Проверки

- Сборка (`vite build`) запускается **на сервере сайта**, не на машине разработки: там
  ограниченная память, сборку легко уронить.
- Dev-сервер локально допустим: `npx vite --host 127.0.0.1 --port 5173`.
- ESLint: `npm run lint`.

## Запреты

- Не заходить в каталоги чужих проектов на сервере: `/var/www/kogti`, `/var/www/beautyopt`,
  `/var/www/femina`, `/var/www/gera`, а также в их nginx-конфиги.
- Не читать секреты и не выводить их содержимое: `~/.ssh`, `~/.hermes`, `auth.json`, `.env`.
- Не удалять файлы без бэкапа.
- Не деплоить в прод без явного подтверждения владельца.

## Деплой

Выполняет владелец **после** мёржа в `main`. На сервере сайта — команда `update-locusfood`
(она же `/var/www/locusfood/deploy.sh`): `git fetch --all --prune` → `git reset --hard origin/main`
→ `npm install` → `vite build --outDir dist.new` → подмена `dist` (предыдущая сборка остаётся
в `dist.prev`, откат — оттуда).
