### Визуальная структура карточки (после изменений)

```text
┌─────────────────────┐
│                [♥]  │  ← NEW слева вверху, избранное справа вверху
│                     │
│       [ФОТО]        │
│                     │
│  [-15%]       [🛒]  │  ← скидка слева внизу, корзина справа внизу
├─────────────────────┤
│  8,00 Б  /шт        │  ← цена первая (красная если lowest)
│  ~~9,41 Б~~         │  ← старая цена зачёркнутая
│  Творожный кулич    │  ← название после цены
│  В наличии          │
│  ★ 4.7 (12)        │
└─────────────────────┘
```
