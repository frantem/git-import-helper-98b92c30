## Проблемы

### 1. Битый символ в `pickupUtils.ts`

Строка 363: `\`${fmtTime(startH, startM)}��${fmtTime(endH, endM)}`— символ`–` повреждён (UTF-8 mojibake), отсюда вопросительные знаки в UI.

### 2. `calculatePickupTime` не поддерживает распределение готовки по нескольким окнам

Для будущих дней (offset > 0) функция вообще не проверяет `prepTimeMinutes` — просто возвращает полное окно слота. Нет carryover-логики как в `calculateDeliveryTime`.

**Пример**: товар 6ч, окно 3ч → показывает "Завтра 13:30–16:30" вместо того чтобы распределить остаток по окнам.

### 3. `getSellerTimeSlots` в Checkout.tsx не поддерживает carryover

Для выбора даты/времени самовывоза функция проверяет `slotStart + maxPrep` для каждого дня, не учитывая что часть готовки уже "съедена" в предыдущих окнах. При 6ч prep и 3ч окнах — все слоты пусты → все даты заблокированы.

### 4. `isDateDisabledForSeller` блокирует все даты

Вызывает `getSellerTimeSlots` → пустой результат → все даты disabled.
