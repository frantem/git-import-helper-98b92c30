# Страница продавца: компактные посты-статьи + чистая обложка

## 1. Компактные карточки постов («О наших продуктах»)

Вместо больших карточек с фото 4:3 — узкие горизонтальные строки, как на референсе:

```text
┌───────────────────────────────────────────┐
│ Заголовок статьи               ┌───────┐  │
│ Начало текста в 2 строки...    │ фото  │  │
│                                └───────┘  │
└───────────────────────────────────────────┘
```

- Текст слева (заголовок + 2 строки анонса с обрезкой), маленькое фото 64–72px справа.
- На мобиле — вертикальный список (2–3 видимых), на ПК — сетка в 2 колонки.
- Вся карточка кликабельна и ведёт на страницу статьи.

## 2. Отдельная страница статьи

- Адрес: `/seller/:sellerSlug/post/:postSlug`.
- Содержимое: заголовок (H1), фото, полный текст (поле `body`, с сохранением переносов строк), ссылка «Все статьи» / назад к бренду.
- SEO: свой `<title>`, description из начала текста, canonical, JSON-LD `Article` (автор — продавец). Пререндер для ботов и sitemap подключим позже, отдельной задачей.

## 3. Обложка на всю высоту сверху

- Убрать заголовок «Продавец» и верхнюю строку с отступом.
- Фото/видео обложки начинается сразу под шапкой, без белого пространства и без скругления сверху.
- Кнопка «назад» — круглая, полупрозрачная, поверх обложки в левом верхнем углу (с учётом safe-area на iPhone).
