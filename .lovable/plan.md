# Простое и надёжное скачивание сторис

## Что изменится для продавца
- Во всех шаблонах (/seller/story: «В наличии», «Новинка», «Меню») остаётся одна кнопка **«Скачать»**.
- Кнопка «Поделиться» и окно «Изображение готово» удаляются полностью.
- Нажал «Скачать» — через пару секунд файл `locus-story.png` сохраняется на телефон, без дополнительных окон.
- Если что-то пошло не так, вместо бесконечной загрузки появляется сообщение «Не удалось создать изображение, попробуйте ещё раз».

## Важное ограничение iPhone
Сайт в браузере не может положить картинку прямо в «Фото» — это запрещено Apple для всех сайтов. На iPhone картинка сразу скачается в «Файлы → Загрузки» (Safari покажет значок загрузки). Под кнопкой на iPhone будет короткая подсказка: «Файл сохранится в Загрузки. Чтобы добавить в Фото: откройте его и нажмите «Сохранить изображение»». На Android картинка попадёт в Загрузки и сразу видна в Галерее.

## Технические детали
- `useStoryExport`: удалить `handleShare`, `canShareFiles`, `resultUrl`, `closeResult`; оставить только `handleDownload`, который всегда скачивает через ссылку с `download` (Safari iOS 13+ это поддерживает).
- Причина «вечной загрузки» на Android не подтверждена; вероятно, зависает загрузка фото товаров при рендере. Исправление: таймаут на ожидание каждой картинки (≈5 с) и общий таймаут рендера (≈20 с) с понятной ошибкой; убрать двойной рендер для не-Safari браузеров; при ошибке CORS у фото — рендерить без него, а не висеть.
- `StoryEditorLayout`: убрать кнопку «Поделиться», `StoryResultDialog` и связанные пропсы; одна широкая кнопка «Скачать» + подсказка только на iPhone.
- Удалить `StoryResultDialog.tsx`; обновить `SellerStoryStock`, `SellerStoryAbout`, `SellerStoryMenu` под новые пропсы.
- Проверка: esbuild правленых файлов, Playwright — клик «Скачать» в десктопном и мобильном (Android UA) режиме создаёт файл.
