# Оценка продавца → страница всех отзывов

## Что сейчас

В карточке товара маленький блок продавца показывает только среднюю оценку (звезда + число), без количества отзывов. Отдельной страницы с отзывами продавца в проекте нет — есть только отзывы по конкретному товару внизу карточки товара и агрегированные рейтинги на витрине продавца `/seller/:id`.

## Что делаем

1. **Блок продавца в карточке товара**
   - Рядом со средней оценкой добавляем количество оценок в скобках: `4,8 (23)`.
   - Оценка становится отдельной кликабельной кнопкой (подчёркивание, стрелка), визуально отделённой от ссылки на страницу продавца, и ведёт на новую страницу всех отзывов продавца.

2. **Новая страница «Отзывы о продавце»** — маршрут `/seller/:id/reviews`
   - Шапка: фото/имя продавца, средняя оценка, общее количество отзывов, распределение по звёздам (5→1).
   - Список всех отзывов по всем товарам продавца (включая архивные/удалённые товары, чтобы история не терялась): имя автора, дата, звёзды, текст, фото отзыва с лайтбоксом.
   - У каждого отзыва — название товара ссылкой на его карточку.
   - Сортировка: сначала новые. Пагинация «Показать ещё» по 20 отзывов.
   - Пустое состояние: «У продавца пока нет отзывов».
   - Кнопка «Назад», мета-теги и `noindex` не нужен — страница индексируемая, с заголовком «Отзывы о {продавец}».

3. **Данные**
   - Средняя оценка и количество считаются по всем отзывам всех товаров продавца — так же, как уже делает хук продукта, только дополнительно возвращаем счётчик.

## Технические детали

- `src/hooks/useProduct.ts`: вернуть `farmerReviewCount` рядом с `farmerRating`.
- Новый хук `src/hooks/useSellerReviews.ts`: по `farmerId` тянет товары продавца, затем `reviews` с фото (`review_images`) и профили авторов, отдаёт агрегаты + список с `productTitle`/`productSlug`.
- Новая страница `src/pages/SellerReviews.tsx`, lazy-роут `/seller/:id/reviews` в `src/App.tsx` (регистрировать до `/seller/:id`).
- `src/pages/Product.tsx`: блок оценки вынести из внешнего `<Link>` продавца в отдельный `<Link>` на `/seller/{farmer_id}/reviews`, добавить `({count})`.
- На витрине продавца (`SellerTrustFooter`) ссылку «Все отзывы» перевести на ту же страницу вместо каталога.
