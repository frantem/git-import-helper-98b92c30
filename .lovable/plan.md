

## Проблема

В предыдущей правке цена отображения была изменена на `6,90`, но **расчётная** стоимость доставки в `src/pages/Checkout.tsx` (строка 349) осталась `700` копеек (= 7 руб). Из-за этого итоговая сумма заказа и сумма, передаваемая в `Purchase` (Meta Pixel/CAPI) и в БД, считается по старой цене.

## Решение

### Файл `src/pages/Checkout.tsx`

Строка 349 — изменить:
```ts
const deliveryCost = deliveryType === "courier" ? 700 : 0; // 7р = 700 kopecks
```
на:
```ts
const deliveryCost = deliveryType === "courier" ? 690 : 0; // 6,90р = 690 kopecks
```

После этого:
- Итоговая сумма в карточке «Итого» будет считаться корректно (товары + 6,90).
- Сумма заказа, сохраняемая в `orders.total_price`, будет корректной.
- Событие `Purchase` в Meta Pixel/CAPI получит корректное `value`.

## Файлы

- `src/pages/Checkout.tsx` — строка 349, заменить `700` → `690`.
