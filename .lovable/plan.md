# Блок «О нас»: стандартные карточки по референсу

## Что меняется

1. **Фото обязательно.** В редакторе продавца (`/seller/page`) пост нельзя сохранить без фото: поле помечается как обязательное, при попытке сохранить без изображения — тост «Добавьте фото». На странице продавца посты без фото просто не показываются, поэтому вариант «карточка без фото» исчезает, и все карточки одинаковые.

2. **Один формат для всех карточек** — точно как на референсе:
   - пропорция карточки 2:3 (портрет), радиус ~24px, лёгкая тень;
   - ширина одна для всех: ~66% экрана (макс. 280px), следующая карточка «подглядывает» справа;
   - фото заполняет всю карточку;
   - снизу — «стеклянная» плашка: размытие самого фото + мягкое затемнение сверху вниз (без цвета темы);
   - на плашке: заголовок (белый, крупный, как «Lakeshore Blvd West»), под ним текст 2–3 строки, под текстом «Читать дальше».

3. **Качество фото.** Сейчас фото тянется через CDN-пресет `card` (240×240, обрезка в квадрат) — для портретной карточки это апскейл и мыло. Добавляется отдельный пресет `post` (360×540, fit cover, q 82, retina 2x), карточка использует его. Фото становится резким и без квадратной обрезки.

4. **«Читать дальше» видно всегда, когда текст не поместился.** Порог по длине убирается: ссылка показывается для любого поста, где текст обрезан (более 3 строк по факту — считаем по длине с более низким порогом), стоит отдельной строкой под текстом, белая, с подчёркиванием. По нажатию карточка растёт вниз: текст раскрывается полностью на той же размытой плашке, ссылка меняется на «Свернуть».

## Технические детали

- `src/lib/imageCdn.ts` — новый пресет `post: { w: 360, h: 540, q: 82, fit: "cover" }`, DPR-кап 2.
- `src/components/seller/SellerPosts.tsx` — переписывается: фильтр `posts.filter(p => p.image_url)`, единый `w-[66%] max-w-[280px] aspect-[2/3]`, фото `absolute inset-0 object-cover` с `preset="post"`, плашка снизу — второй экземпляр того же изображения с `blur` + маска/градиент (или `backdrop-blur` поверх фото), поверх него заголовок → текст (`line-clamp-3` в закрытом виде) → кнопка. При раскрытии карточка выходит за `aspect-[2/3]` вниз (высота по контенту), лента не ломается.
- `src/pages/seller/SellerPage.tsx` — в блоке постов: подпись «Фото (обязательно)», в `savePost` проверка `image_url` перед запросом.
- Схема БД, роуты и хуки не меняются.
