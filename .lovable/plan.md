## Что меняем
В `/admin/commission` (`src/pages/admin/AdminCommission.tsx`) сейчас кнопка «Рассчитано» стоит у каждого товара (`ItemRow`). Нужно, чтобы по каждому продавцу в заказе была одна кнопка, закрывающая все его позиции разом.

## План

1. **`src/hooks/useCommission.ts`** — добавить мутацию `useSettleItems` (bulk):
   - принимает `itemIds: string[]`
   - один запрос: `supabase.from("order_items").update({ settled_at, settled_by }).in("id", itemIds)`
   - инвалидация `["commission"]`
   - существующую `useSettleItem` оставляем (используется во вкладке «Долги (самовывоз)»).

2. **`src/pages/admin/AdminCommission.tsx`**:
   - В `SellerGroup` добавить кнопку «Рассчитано» рядом с итогом продавца. По клику — `useSettleItems.mutate({ itemIds: items.map(i => i.item_id) })` с toast об успехе/ошибке и состоянием `disabled` во время запроса.
   - Из `ItemRow` убрать кнопку «Рассчитано» **только в режиме `mode="payout"`** (вкладка «К расчёту по дням»), оставив её для `mode="debt"` (вкладка «Долги (самовывоз)»), где расчёт по-прежнему пер-товарный по смыслу (комиссия за конкретные позиции самовывоза).
   - Поведение группировки/сумм не меняем.

## Чего НЕ трогаем
- БД, RLS, политику, типы.
