## Цель

Чтобы карточки товаров Locus попадали в топ Google/Яндекс по запросам типа "купить страчателла Витебск", поисковики должны:
1. Успешно прочитать `sitemap.xml` (сейчас падает с ошибкой).
2. Видеть на странице товара полноценный HTML с заголовком, описанием, ценой и микроразметкой (это уже работает через prerender).

Этот план фиксит блокер №1 и усиливает п.2 точечными правками, без изменения бизнес-логики.

## Что не так сейчас

Google Search Console ругается:
> Строка 105, тег `image`, родитель `url` — неправильно указано пространство имён.

Причина: в Edge Function `sitemap` объявлено
`xmlns:image="http://www.google.com/schemas/sitemaps-image/1.1"` (с лишней `s` — `sitemaps-image`).
Корректный URL по [спецификации Google](https://www.google.com/schemas/sitemap-image/1.1) — `sitemap-image` (без `s`).
Из-за этого все `<image:image>` блоки в sitemap считаются невалидными, и Google перестаёт читать файл.

В файле `supabase/functions/sitemap/index.ts` в репозитории уже стоит правильный вариант (`sitemap-image`), но на проде отдаётся старый — значит функция была задеплоена раньше с опечаткой, либо локальная правка не дошла. Передеплой исправит.

## План

### 1. Починить sitemap (главный фикс)

Файл: `supabase/functions/sitemap/index.ts`

- Убедиться, что объявление namespace ровно такое:
  `xmlns:image="http://www.google.com/schemas/sitemap-image/1.1"`
- Перевыкатить функцию (деплой произойдёт автоматически при сохранении).
- После деплоя проверить `curl -sL https://locusfood.by/sitemap.xml | sed -n '1,3p'` — в строке 2 должен быть правильный URL без лишней `s`.
- В Search Console нажать "Отправить" sitemap заново.

### 2. Усилить sitemap для лучшей индексации товаров

В том же файле:

- Поднять `<priority>` товаров с `0.8` до `0.9` — это основной коммерческий контент.
- Для каждого товара добавить `<image:caption>` с названием товара рядом с `<image:title>` — Google использует подпись в Image Search.
- Отсортировать `products` так, чтобы свежеобновлённые шли первыми (уже сделано через `order updated_at desc` — оставить).
- Добавить категорийные `/catalog?category=<slug>` уже есть — оставить.

### 3. Подтвердить, что страница товара отдаётся ботам с полным HTML

Файл: `supabase/functions/prerender/index.ts` (только чтение, чтобы убедиться)

- Проверить, что для маршрута `/product/:id` prerender вставляет:
  - `<title>` вида `{Название} — купить в Витебске с доставкой | Locus`
  - `<meta name="description">` с ценой, фермером, городом
  - JSON-LD `Product` с `offers.price`, `availability`, `aggregateRating` (если есть отзывы)
  - `<h1>` с названием товара
- Эта логика уже реализована (см. `src/lib/seoHelpers.ts` → `productTitle`, `productDescription`, `productJsonLd`). План — только убедиться, что prerender их использует. Если нет — внести точечные правки.

### 4. Усилить локальный сигнал "Витебск" на странице товара

Файл: `src/pages/Product.tsx` (только если в текущем HTML недостаёт)

- Добавить в видимый текст страницы строку "Доставка по Витебску" рядом с ценой/кнопкой "Заказать" (если её там ещё нет). Поисковики ранжируют по тексту, который виден пользователю.
- Никакой бизнес-логики не трогаем — только текстовый элемент в существующей секции.

### 5. После деплоя

- Заново отправить `https://locusfood.by/sitemap.xml` в Google Search Console.
- В Яндекс.Вебмастере добавить тот же URL в разделе "Файлы Sitemap".
- В Search Console для 3–5 ключевых товаров (включая страчателлу `2a5f3c88-…`) нажать "Проверка URL" → "Запросить индексирование" — это ускорит переобход.

## Технические детали

- Меняется только Edge Function `sitemap` (1 строка namespace + 2 строки `<priority>`/`<image:caption>`) и опционально один текстовый блок в `Product.tsx`.
- Никаких миграций БД, никаких изменений RLS, никаких новых секретов.
- Контракт sitemap не ломается: URL и схема ответа те же, исправляется только синтаксическая ошибка XML.
- Кэш sitemap — 10 минут (`s-maxage=1200`), так что после деплоя надо подождать или принудительно обновить через `?v=2` в Search Console.

## Чего этот план НЕ делает

- Не добавляет новые страницы и не меняет роутинг.
- Не трогает оформление товара, корзину, checkout.
- Не гарантирует топ-1 за день — индексация и ранжирование занимают 1–4 недели после фикса sitemap. План закрывает технические блокеры; дальше Google сам подтянет страницы.
