# Страница продавца: пересборка под конверсию

Цель — довести покупателя с первого экрана до «В корзину» минимумом действий, сохранив доверие. Мобайл-фёрст, один столбец, единая сетка отступов и единый радиус карточек.

## Новая структура (сверху вниз)

```text
1  HERO   фото/видео, кнопка «назад», имя бренда,
          одна фраза-факт уникальности,
          бейджи: ✅ Проверено LOCUS · 📍 локация · N заказов
          CTA «Смотреть каталог» → скролл к блоку 6
2  О НАС  круглое фото продавца + 2–4 предложения от первого лица
3  ХИТЫ   3–4 товара, свайп-лента, цена + «В корзину» на карточке
4  ДОСТАВКА  компактная плашка: способ, время, стоимость
5  АКЦИИ И НАБОРЫ  карточки размером как товарные, свайп-лента
6  КАТАЛОГ ПО КАТЕГОРИЯМ  как сейчас: заголовок → сетка
7  ФУТЕР ДОВЕРИЯ  «Все отзывы о нас — на площадке LOCUS →»
          + контакты/соцсети продавца
```

Блок «О наших продуктах / О нас» (посты-статьи) остаётся, но переезжает ниже хитов — между блоками 4 и 5, чтобы товар был раньше контента.

Отзывы с личной страницы полностью убираются: вместо них ссылка на карточку продавца в общем каталоге LOCUS (`/catalog?seller=<slug>`), где отзывы и живут. Отдельную страницу отзывов не делаем.

## Что настраивает продавец в «Моя страница»

- Факт уникальности (одна строка). Пока не заполнен — на странице показывается плейсхолдер `[УНИКАЛЬНЫЙ_ФАКТ_ПРОДАВЦА]`, ничего не придумываем.
- Текст «О нас» (от первого лица) и круглое фото продавца/семьи.
- Хиты: вручную отмечает до 4 своих товаров.
- Строка про доставку/самовывоз (способ, ориентировочное время, стоимость).
- Контакты и соцсети.
- Цветовая тема — пока одна, «Лес» (`#234835` / `#9ddc09` / `#faf5ea`), заведена как набор CSS-переменных, чтобы позже добавить ещё темы без переделки макета.

## Технические детали

База (миграция):
- `farmers`: `unique_fact text`, `delivery_note text`, `contacts jsonb` (телефон/Instagram/Telegram), `theme text default 'forest'`. Фото «о нас» — существующее `photo_url`.
- Хиты — существующий `products.is_featured`: продавец переключает флаг в «Моя страница» (ограничение 4 в UI).
- Счётчик заказов: новая SECURITY DEFINER функция `get_farmer_public_stats(_farmer_id uuid)` → `orders_count` (подтверждённые `order_items` продавца), `EXECUTE` для `anon`/`authenticated`; `order_items` напрямую анонимам не открываем.

Фронтенд:
- `SellerHero`: слабее градиент (читаемость), ряд бейджей, факт уникальности, CTA-кнопка со скроллом к `#seller-catalog`.
- Новые компоненты в `src/components/seller/`: `SellerAbout`, `SellerHits`, `SellerDelivery`, `SellerTrustFooter`.
- `SellerHits`: карточка с фото, названием, ценой (`BynSymbol`) и кнопкой «В корзину» через `useCart().addToCart` с дефолтным вариантом — без перехода на страницу товара; тап по фото/названию всё же ведёт на товар.
- `SellerPromos`: уменьшаем до размера товарных карточек в той же свайп-ленте.
- `SellerProfile.tsx`: убираем блок отзывов и его запросы (`fetchSellerReviews`, лайтбокс, удаление отзыва), добавляем хиты, доставку, футер доверия; сохраняем группировку по категориям и `ProductCard`.
- `Catalog.tsx`: поддержка параметра `?seller=<slug>` — фильтр товаров продавца, чтобы ссылка из футера доверия вела на его карточку в маркетплейсе.
- `src/pages/seller/SellerPage.tsx`: новые поля редактирования (факт, о нас, фото, хиты, доставка, контакты).
- Цвета — только через токены (`--brand-deep`, `--accent`, фон `#faf5ea` переводим в токен темы), без хардкода утилит вроде `text-white`.
- Все изображения через `OptimizedImage`/`cdnImage`, hero — приоритетно, остальное `lazy`; пустые блоки не рендерятся.
- SEO: `SEO`-теги сохраняются, в description попадает факт уникальности; prerender продолжает работать.
