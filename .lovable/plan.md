## Цель
На вкладке «К расчёту по дням» в `/admin/commission` группировать не «день → продавец», а **день → заказ → продавец → товары**. В шапке каждого заказа — `#shortId` и ожидаемое время доставки (например `01.06 19:30–20:30`), как на `/admin/orders`.

## Правки

**`src/hooks/useCommission.ts`**
- В `select(...)` для `orders` добавить поля `estimated_delivery_time` и `total_amount` (последнее не обязательно, но пригодится для шапки).
- В тип `CommissionItem` добавить `estimated_delivery_time: string | null` и прокинуть значение в маппинге.

**`src/pages/admin/AdminCommission.tsx`** (только вкладка «К расчёту по дням», вкладка «Долги (самовывоз)» не трогаем)
- Поменять группировку:
  ```
  day → Map<order_id, { order_id, estimated_delivery_time, sellers: Map<farmer_id, items[]> }>
  ```
- Рендер:
  - Заголовок дня — как сейчас (`dateLabel(day)` + итог по дню).
  - Внутри дня — карточки заказов:
    - Шапка заказа: `Заказ #<первые 8 символов order_id>` слева, справа — `estimated_delivery_time` (если есть). Сумма к выплате по заказу.
    - Внутри — те же `SellerGroup` (схлопываемые) с товарами и кнопкой «Рассчитано» на каждом `order_item` (логика без изменений).
- Короткий ID: `order_id.slice(0, 8)`.
- Если у заказа нет `estimated_delivery_time` — не показывать пустую строку.

**Что НЕ меняем**
- Логика комиссии (10% / 5% реферал) — без изменений.
- Фильтры `delivery_type` — без изменений (`courier` → выплаты, `pickup`+`self` → долги).
- Кнопка «Рассчитано» и хук `useSettleItem` — без изменений.
- Карточки сверху с итогами — без изменений.
- Вкладка «Долги (самовывоз)» — без изменений.
