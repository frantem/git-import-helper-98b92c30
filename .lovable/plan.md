

## План: Убрать текстовые поля с баннеров

Баннеры теперь будут только изображениями без наложенного текста. Нужно убрать текстовые поля из формы админки, градиент-оверлей из карусели, и соответствующие поля из трансформации данных.

### Изменения

**1. `src/pages/admin/AdminBanners.tsx`**
- Убрать поля формы: `title` (сделать скрытым/автоматическим — столбец NOT NULL, поэтому будем ставить дефолтное значение, например имя файла или "Баннер"), `subtitle`, `discount_text`
- Убрать из формы 3 Input-а (Заголовок, Подзаголовок, Дополнительный текст)
- Убрать селектор градиента и его превью (раздел "Затемнение")
- `title` — столбец NOT NULL в БД, поэтому при сохранении ставим `title: "Баннер"` или генерируем из номера. В форме показывать необязательное поле "Название (для себя)" для удобства идентификации в списке

**2. `src/components/BannerCarousel.tsx`**
- Убрать div с градиентом и текстом (строки 108-125) — оставить только изображение
- Упростить интерфейс `Banner`: убрать `subtitle`, `discountText`, `colorGradient` (title оставить для alt)

**3. `src/hooks/useBanners.ts`**
- Упростить `transformBanner`: убрать `subtitle`, `discountText`, `colorGradient`

### Результат
- Форма создания баннера: загрузка изображения + название (для себя) + ссылка + порядок + активность
- Карусель: только изображение, без текста и затемнения
