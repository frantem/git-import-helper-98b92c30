## Открытие фото товара в полноэкранном режиме

Сейчас на странице товара (`/product/:id`) фото в карусели — статичные, по тапу ничего не происходит. Сделаю лайтбокс: тап по фото открывает его на весь экран, можно листать свайпом/стрелками и приближать (pinch-to-zoom на мобильных, двойной тап / колесо на десктопе).

### Что увидит пользователь

- Тап по любому фото в карусели на странице товара → открывается полноэкранное окно с этим фото на чёрном фоне.
- Снизу — счётчик «2 / 5» и точки-индикаторы.
- Свайп влево/вправо (или стрелки на десктопе) — листание между фото.
- Pinch-zoom на телефоне, двойной тап для приближения, колесо мыши — на десктопе.
- Крестик сверху справа и тап вне фото / Esc — закрыть.
- Открывается всегда то фото, по которому тапнули (не первое).

### Технические детали

**Новый компонент** `src/components/ProductImageLightbox.tsx`:
- Обёртка над существующим `Dialog` (Radix) c кастомным `DialogContent` без рамок (`max-w-screen h-screen bg-black/95`, без padding).
- Внутри — `Carousel` (embla, уже используется) с `opts={{ startIndex, loop: true }}`.
- Для зума — лёгкая библиотека `react-zoom-pan-pinch` (≈8 KB gzip, поддерживает pinch и двойной тап) либо ручная реализация на CSS-transform + touch-events. Предпочитаю `react-zoom-pan-pinch` — стабильнее, меньше багов на iOS Safari.
- Картинки грузятся пресетом `detail` через существующий `OptimizedImage` / `cdnImage` — без лишнего egress.
- Закрытие: крестик (`X` из lucide), клик по фону, Esc (Radix даёт это бесплатно).
- Счётчик и точки внизу — на основе `api.selectedScrollSnap()` из embla.

**Правка `src/pages/Product.tsx`** (строки 597–611):
- Завернуть `<OptimizedImage>` внутри `CarouselItem` в `<button onClick={() => openLightbox(index)}>` с `cursor-zoom-in`.
- Для случая одного фото — тоже сделать кликабельным.
- Добавить состояние `const [lightboxIndex, setLightboxIndex] = useState<number | null>(null)` и рендер `<ProductImageLightbox images={allImages} startIndex={lightboxIndex} onClose={() => setLightboxIndex(null)} />`.
- Кнопки «избранное» и «поделиться» (строки 618–629) уже имеют `z-10` и `stopPropagation` — клик по ним не должен открывать лайтбокс. Проверю, что обработчик на изображении не перехватывает их.

**Зависимость**: `bun add react-zoom-pan-pinch`.

**Файлы**:
- создать: `src/components/ProductImageLightbox.tsx`
- изменить: `src/pages/Product.tsx`
- изменить: `package.json` (через `bun add`)

### Что не трогаю

- Карусель на самой странице товара остаётся как есть.
- Превью/карточки товара — без изменений (egress не растёт, лайтбокс грузит тот же `detail`-пресет).
- SEO/пререндер — не затрагивается (лайтбокс рендерится только по клику).
