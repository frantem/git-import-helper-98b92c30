## Безопасность

Email сохраняется без подтверждения — теоретически пользователь может вписать чужой адрес. Но:
- `auth.users.email` остаётся виртуальным → нельзя залогиниться по чужой почте.
- `profiles.email` используется только для исходящих уведомлений → максимум, чужой человек получит письмо о чужом заказе. Риск приемлемый, т.к. пользователь сам себе вредит.
- Если позже нужна гарантия владения — Settings уже имеет полный OTP-флоу для «настоящей» смены почты с обновлением auth.
