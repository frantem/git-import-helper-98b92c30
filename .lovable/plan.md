## Цель

В `/admin/orders` добавить возможность вручную менять дату доставки (`delivery_date`) и ожидаемое время (`estimated_delivery_time`) у любого заказа. Изменения сохраняются в таблицу `orders` и автоматически отображаются у продавца (`/seller/orders`) и покупателя (`/orders`), так как они уже читают эти же поля.

## Что меняется

Только UI в `src/pages/admin/AdminOrders.tsx`. Никаких изменений в БД, RLS, edge-функциях, бизнес-логике расчётов, уведомлениях. RLS уже разрешает админу `UPDATE orders`.

## Реализация

1. В карточке каждого заказа рядом со строками «Доставка: …» и «Ожидаемое время: …» добавить маленькую кнопку-иконку (карандаш, `Pencil` из lucide).
2. По клику открывается общий `Dialog` для этого заказа с двумя полями:
   - Дата доставки — `<Input type="date">`, значение из `delivery_date` (формат `YYYY-MM-DD`, как уже хранится).
   - Ожидаемое время — `<Input type="text" placeholder="например, 14:00–16:00">`, значение из `estimated_delivery_time` (свободный текст, как сейчас).
3. Кнопки «Отмена» и «Сохранить». При сохранении:
   - `supabase.from("orders").update({ delivery_date, estimated_delivery_time }).eq("id", order.id)`
   - Пустая строка → `null`.
   - `toast.success("Изменения сохранены")` + локальное обновление состояния `orders` (без полного перезапроса, чтобы не дёргать список).
4. Если у заказа сейчас нет даты/времени — кнопка «Изменить дату/время» появляется отдельной строкой, чтобы можно было задать впервые.

## Что НЕ трогаем

- Логику авторасчёта `estimated_delivery_time` при создании/подтверждении заказа.
- Уведомления продавцу/покупателю — ручное изменение даты не триггерит писем.
- Проверки расписания продавца, слотов самовывоза, busy/vacation dates — админ ставит что хочет.
- Страницы продавца и покупателя — они уже читают `delivery_date` и `estimated_delivery_time` напрямую и сразу покажут новые значения после обновления.

## Технические детали

- Состояние диалога: `const [editing, setEditing] = useState<{ id: string; date: string; time: string } | null>(null)`.
- Используем существующие shadcn компоненты: `Dialog`, `Input`, `Label`, `Button`.
- Импорт `Pencil` добавить в существующий импорт из `lucide-react`.
