# Видео вместо скриншота в первом блоке /for-sellers

## Цель
Заменить статичный скриншот «Реальная страница продавца на Locus» в hero-блоке лендинга `/for-sellers` на загруженное видео `IMG_8289.MP4` (37 сек, вертикальное 888×1766).

## Проблема формата
Видео закодировано в HEVC (H.265) — оно не воспроизводится в Chrome, Firefox и на большинстве Android-устройств. Перед использованием его нужно перекодировать.

## Что будет сделано

1. **Подготовка видео (ffmpeg)**
   - Перекодировать в H.264 MP4 (совместим со всеми браузерами).
   - Слегка сжать (цель ~5–10 МБ вместо 45 МБ), сохранить вертикальный формат.
   - Убрать звуковую дорожку — видео будет играть без звука.

2. **Загрузка как CDN-ресурс**
   - Через `lovable-assets` создать указатель `src/assets/knyazhetsky-page-video.mp4.asset.json` — видео не попадёт в репозиторий, будет раздаваться с CDN.

3. **Изменение `src/pages/ForSellers.tsx`**
   - В hero-блоке внутри «телефонной» рамки заменить `<img>` на `<video>` с атрибутами: `autoPlay`, `muted`, `loop`, `playsInline` (обязательно для iPhone).
   - В качестве `poster` оставить текущий скриншот — он показывается до загрузки видео и при слабом интернете.
   - Подпись «Реальная страница продавца на Locus» остаётся.
   - Второй блок с примером (секция доверия, «Так теперь выглядит страница...») не меняется — там остаётся статичный скриншот.

4. **Проверка**
   - Открыть `/for-sellers` на десктопе и мобильном размере 393×852 через Playwright: видео автозапускается, зациклено, без звука, не ломает верстку и sticky-кнопку.

## Не входит
- Изменение остальных секций лендинга.
- Использование видео в других местах сайта.
