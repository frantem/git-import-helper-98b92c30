# Тарифы: убрать лимит товаров и сделать компактную таблицу

## Что изменится

### 1. Убрать ограничение по количеству товаров
- В «Мои товары» (`/seller/products`) снять блокировку активации товаров для Free: продавец может включать любое количество товаров.
- Убрать баннер «Тариф Free: активными могут быть только 3 товара…» и заменить его на апселл без упоминания лимитов: «Подключите Standard — продавайте без комиссии, открывайте контакты клиентов и показывайте свои контакты на странице бренда» + кнопка «Подключить Standard» (показывается только на Free).

### 2. Убрать строку «Товары» из таблицы тарифов
Из `/seller/tariffs` удалить строку «Товары (до 3 / до 30 / без лимита)» — и в таблице, и в мобильных карточках.

### 3. Один компактный вид таблицы на всех экранах
Вместо двух вариантов (таблица на десктопе, карточки на мобильном) — одна таблица, которая помещается по ширине экрана без горизонтальной прокрутки:
- 4 колонки: Функция / Free / Standard / Pro; колонка Standard выделена фоном и бейджем «Рекомендуем».
- Длинные названия функций переносятся на две строки (например «Все контакты клиентов / открыты», «Можете сами / делать доставку», «Комиссия / с продажи»), шрифт мельче на узких экранах.
- Колонки тарифов узкие и фиксированной ширины, ячейки — галочка / тире / короткое значение; последняя строка «Стоимость».
- Мобильные карточки-дубликаты удаляются.

Логика тарифов, пробного периода, цен и заявок не меняется.

## Техническая часть
- `src/pages/seller/SellerProducts.tsx`: удалить `FREE_ACTIVE_LIMIT` и проверку в `handleToggleActive`, переписать текст баннера (оставить `plan === "free"` условие и ссылку на `/seller/tariffs`).
- `src/pages/seller/SellerTariffs.tsx`: убрать пункт «Товары» из массива `FEATURES`, добавить в записи поле короткой второй строки для переноса, удалить `md:hidden` блок карточек и `hidden md:block` у таблицы; таблица получает `table-fixed`, `text-[11px] sm:text-sm`, узкие колонки тарифов и `leading-tight` для многострочных подписей.
- Стили — только семантические токены, цены по-прежнему в копейках через `formatPrice` + `<BynSymbol />`.
