# Блок постов на странице продавца: свой заголовок + горизонтальный слайдер

## Что меняем

1. **Название блока настраивается продавцом.** В «Панель продавца → Моя страница» добавляем поле «Заголовок блока о нас» рядом с настройками блока постов. Значение по умолчанию — «О нас» (вместо текущего «О наших продуктах»). Если продавец ничего не задал, на публичной странице показывается «О нас».

2. **Посты — в одну строку с горизонтальной прокруткой.** Вместо сетки в 2 колонки карточки выстраиваются в один горизонтальный ряд:
   - ширина карточки примерно вдвое меньше текущей, так что за первой карточкой видна половина второй (подсказка, что можно листать);
   - прокрутка вправо свайпом/скроллом, с плавным доводом (scroll-snap), полоса прокрутки скрыта;
   - содержимое карточки то же: заголовок, 2 строки текста, маленькое фото справа, ссылка на страницу статьи.

## Технические детали

- Миграция: новая колонка `farmers.posts_block_title text` (nullable). Существующие продавцы получают `null` → фронтенд подставляет «О нас».
- `src/hooks/useSellerPage.ts` / `SellerProfile.tsx`: добавить `posts_block_title` в выборку колонок фермера и передать в `SellerPosts` как `blockTitle`.
- `src/components/seller/SellerPosts.tsx`: новый пропс `blockTitle?: string | null` (fallback «О нас»); контейнер меняется с `grid gap-2 md:grid-cols-2` на `flex overflow-x-auto snap-x` c карточками `w-[65%] shrink-0 snap-start` (на десктопе — узкий фиксированный размер), фото уменьшается до ~56px.
- `src/pages/seller/SellerPage.tsx`: инпут для `posts_block_title` сохраняется вместе с остальными полями фермера в существующем обработчике сохранения.
- Прочие блоки (обложка, акции, товары, отзывы) не трогаем.
