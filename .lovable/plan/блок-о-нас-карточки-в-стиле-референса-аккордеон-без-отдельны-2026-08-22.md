# Блок «О нас»: карточки в стиле референса + аккордеон, без отдельных страниц

## Что меняется

1. **Никаких отдельных страниц постов.** Роут `/seller/:sellerSlug/post/:postSlug`, страница `SellerPost.tsx` и хук `useSellerPost` удаляются целиком — сайт становится легче (минус lazy-чанк). Данные постов по-прежнему приходят одним запросом вместе со страницей продавца.
2. **Новый дизайн карточки (по референсу).** Каждая карточка — крупное фото с закруглением, поверх фото:
  - плашка-пилюля слева сверху (полупрозрачная, размытый фон) с коротким акцентом — заголовок поста;
  - снизу тёмный градиент, на нём текст: первые 2–4 предложения поста (обрезка по строкам);
  - под текстом широкая светлая кнопка-пилюля «Читать дальше» (как «Reserve» на референсе). Не нужно делать эту кнопку нужно сделать просто незаметную маленький текст «Читать дальше» и только если текст не вместился в эту карточку.  
   Если фото у поста нет — та же карточка на фоне темы (`--seller-deep`), без изображения.
3. **Аккордеон внутри блока.** Нажатие «Читать дальше» разворачивает остаток текста в этой же карточке: карточка вырастает вниз, текст показывается полностью на светлой подложке, кнопка меняется на «Свернуть». Никакой навигации, никакого сброса скролла — состояние хранится локально в компоненте, страница не перерисовывается заново.
4. **Раскладка блока.** Остаётся горизонтальная лента со снап-скроллом, но карточки становятся вертикальными (фото + подпись), ширина ~72% экрана с «подглядыванием» следующей. При раскрытии карточка расширяется по высоте, лента не ломается.
5. Заголовок блока (настраиваемый продавцом, по умолчанию «О нас») сохраняется без изменений.

## Технические детали

- `src/components/seller/SellerPosts.tsx` — переписывается: `Link` → `button` + локальный `Set` раскрытых id; фото через `OptimizedImage` (preset `card`), градиент и цвета только через токены `--seller-*` / семантические классы, единый радиус `rounded-2xl`.
- `src/App.tsx` — убрать `lazy` импорт и `<Route path="/seller/:sellerSlug/post/:postSlug" ...>`.
- `rm src/pages/SellerPost.tsx`; из `src/hooks/useSellerPage.ts` удалить `useSellerPost` и тип `SellerPostPage`.
- `src/pages/SellerProfile.tsx` — у `SellerPosts` больше не нужен `sellerSlug`.
- В prerender/sitemap ссылок на посты нет — правки не требуются. Таблица `seller_posts` и редактор в панели продавца не меняются.
