# Панель продавца: страница «Создать изображение» (сторис 1080×1920)

## Что получит продавец

Новый пункт «Создать изображение» в панели продавца (`/seller`) и отдельная страница по стабильному адресу **`/seller/story`** (позже на неё сможет ссылаться Telegram-бот).

### 1. Список товаров
- Показываются только товары продавца с включённым тумблером активности (`is_active = true`, не удалённые).
- Выбор чекбоксами, максимум 4 (при достижении лимита остальные чекбоксы блокируются, подпись «Выбрано 4 из 4»).
- Пустое состояние, если активных товаров нет: «Отметьте товары как "в наличии", чтобы создать сторис» + ссылка на `/seller/products`.

### 2. Выбор фона
- Галерея готовых фонов (4–6 штук). Сейчас — заглушки-плейсхолдеры (мягкие однотонные/градиентные фоны в палитре сайта); когда вы пришлёте свои картинки, я просто подменю файлы в `src/assets/story-backgrounds/`.
- Кнопка «Загрузить своё»: выбор файла → диалог обрезки 9:16 (тот же `react-easy-crop`, что и для товаров) → результат 1080×1920 в режиме cover без искажений. Хранится только в памяти текущей сессии (без загрузки в Storage).

### 3. Живой превью (обновляется мгновенно)
Холст 1080×1920, на экране показывается уменьшенным (по ширине контейнера), при экспорте рендерится в полном размере:
- Фон на всю площадь.
- Сверху — **редактируемый заголовок** (по умолчанию «Выбор покупателей:»), поле ввода над превью; крупный жирный шрифт, светлый текст с мягкой тенью.
- По центру — карточки товаров в стиле сайта (фото 1:1, скругление `rounded-2xl`, тень, название, цена с `BynSymbol`, старая цена, бейдж скидки, срок «Сегодня/В наличии/~Nч.»). **Без сердечка и корзины.** Раскладка зависит от количества:
  - 1 товар — одна крупная карточка по центру
  - 2 — в ряд
  - 3 — две сверху, одна по центру снизу
  - 4 — сетка 2×2
- Нижняя зона — полупрозрачная размытая скруглённая плашка (стеклянный эффект: `backdrop-blur`, белый с прозрачностью ~15–20%, тонкая светлая рамка) с ненавязчивым, но читаемым текстом «Переходите на сайт и заказывайте, ссылка в шапке профиля». Текст не редактируется.
- Шрифт всего холста — **Manrope** (Google Font с кириллицей), подключается локально через `@fontsource/manrope` только на этой странице, чтобы не утяжелять остальной сайт.

### 4. Кнопки под превью
- **Скачать** — генерирует PNG 1080×1920 и сохраняет файл `locus-story.png`.
- **Поделиться** — Web Share API с файлом (на мобильном откроется системное меню); если браузер не поддерживает шеринг файлов — кнопка скрыта / показывается подсказка «Скачайте и поделитесь вручную».

## Технические детали

- **Роут**: `src/App.tsx` → `/seller/story` (lazy) → новая страница `src/pages/seller/SellerStory.tsx`. Доступ как у остальных страниц панели: роль `seller`/`admin`, иначе редирект.
- **Пункт навигации**: карточка «Создать изображение» (иконка `ImageIcon`) в `src/pages/SellerDashboard.tsx` рядом с остальными.
- **Рендер в PNG**: пакет `modern-screenshot` (`domToBlob`) — современный аналог html2canvas на базе SVG foreignObject, корректно рендерит `backdrop-filter`, шрифты и `object-fit`. Никаких AI-моделей.
  - Скрытый «экспортный» DOM-узел 1080×1920 рендерится в полном размере; на экране показывается тот же компонент через `transform: scale()`.
  - Изображения товаров загружаются в исходном виде с Supabase Storage (не через wsrv.nl), с `crossOrigin="anonymous"`; перед экспортом ждём загрузку всех картинок и `document.fonts.ready`.
  - Fallback: если рендер упал — тост с ошибкой.
- **Компоненты**:
  - `src/components/seller/story/StoryCanvas.tsx` — холст (фон, заголовок, сетка карточек, нижняя плашка).
  - `src/components/seller/story/StoryProductCard.tsx` — упрощённая копия вёрстки `ProductCard` без интерактива (Link/кнопки), с теми же классами скругления/тени/цены; переиспользует `formatPrice`, `calculateOldPrice`, `BynSymbol`, `formatPrepTime`.
  - `src/components/seller/story/BackgroundPicker.tsx` — галерея + загрузка своего фона.
  - `src/components/StoryBackgroundCropDialog.tsx` — вариант crop-диалога с `aspect = 9/16` и выводом 1080×1920 (обобщу существующий `ImageCropDialog` пропсами `aspect`/`outputWidth`/`outputHeight`, не ломая текущее использование 1:1).
- **Данные**: `products` с `variants` (цена по умолчанию, скидка, единица), `prep_time_minutes`, `order_lead_time_hours`, `image_url` — из существующих таблиц; новых таблиц и миграций не требуется.
- **Зависимости**: `modern-screenshot`, `@fontsource/manrope` (только 700/800 начертания, импорт внутри страницы).
- **Фоны**: `src/assets/story-backgrounds/bg-1..6.jpg` — пока временные плейсхолдеры; конфиг-массив в одном месте для лёгкой замены.
