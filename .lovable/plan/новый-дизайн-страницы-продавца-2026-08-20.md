# Новый дизайн страницы продавца

Страница `/seller/:slug` полностью переделывается в 4 блока по мокапу (тёмный «botanical»-стиль), с адаптацией под мобильные. Карточка товара (`ProductCard`) не меняется. Всё содержимое новых блоков продавец редактирует сам в панели продавца.

## Как будет выглядеть страница

```text
┌───────────────────────────────────────┐
│  ФОТО или ВИДЕО (тёмное, скруглённое) │
│                                       │
│   Татьяна и Александр /               │
│   Свое Подворье / Own_Farmstead       │  ← крупно, но в 2 раза меньше мокапа
│   девиз бренда (2-3 строки)           │
│                                       │
│  ┌ карточка «О продавце» ┐            │
│  │ текст о продавце      │  [📍 Витебский, Витебск] │
│  └───────────────────────┘            │
└───────────────────────────────────────┘

2. ПОСТЫ О ПРОДУКТАХ (заголовок + текст + фото, 2-3 в ряд на ПК, свайп-лента на мобиле)

3. АКЦИИ И НАБОРЫ (тёмные карточки-слайды с фото, заголовком, описанием и ссылкой)

4. ТОВАРЫ ПО КАТЕГОРИЯМ (как на главной: «🍰 Торты» → сетка товаров, далее следующая категория)
```

Мобильная адаптация: hero на всю ширину экрана с меньшим шрифтом, карточка «о продавце» и плашка с адресом складываются в столбик, посты и акции — горизонтальные свайп-ленты, товары — сетка 2 в ряд (как сейчас).

## Что продавец сможет настраивать

В панели продавца появляется раздел «Моя страница»:
- название/девиз бренда, текст «о продавце», строка локации;
- hero-медиа: загрузка фото или видео (mp4/webm, лимит ~15 МБ) с превью;
- посты о продуктах: заголовок, текст, фото, порядок, вкл/выкл;
- акции и наборы: заголовок, описание, фото, ссылка (на товар/категорию), порядок, вкл/выкл.

Всё редактируется без кода, изменения сразу видны на публичной странице.

## Технические детали

База (миграция):
- `farmers`: `tagline text`, `about_text text`, `hero_media_url text`, `hero_media_type text` ('image' | 'video'), `location_label text`.
- новая `seller_posts`: `id, farmer_id, title, body, image_url, sort_order, is_active, created_at`.
- новая `seller_promos`: `id, farmer_id, title, description, image_url, link_url, sort_order, is_active, created_at`.
- Для обеих таблиц: `GRANT SELECT` для `anon`/`authenticated`, полный набор для владельца-продавца и `service_role`; RLS — публичное чтение только `is_active = true`, запись владельцу фермера (`farmers.user_id = auth.uid()`) и админу.
- Storage: новый публичный бакет `seller-media` для hero-медиа, фото постов и акций + RLS-политики на `storage.objects` по префиксу `farmer_id`.

Фронтенд:
- `src/pages/SellerProfile.tsx` — новая вёрстка 4 блоков; товары группируются по `categories.name/slug` (порядок — по `sort_order` категорий), рендер через существующий `ProductCard`, заголовки как на главной.
- Новые компоненты: `SellerHero`, `SellerPosts`, `SellerPromos` в `src/components/seller/`.
- Новый хук `useSellerPage(farmerId)` — один параллельный запрос постов и акций через react-query (`staleTime`), чтобы не тормозить загрузку.
- Панель продавца: новая страница `src/pages/seller/SellerPage.tsx` (маршрут `/seller-page`) + ссылка из `SellerDashboard`; загрузка изображений через существующий `compressImage`, видео — без сжатия с проверкой размера.

Производительность и надёжность:
- изображения через `OptimizedImage`/`cdnImage` (CDN-ресайз), видео `muted playsInline preload="metadata"` c poster-кадром и авто-фолбэком на фото при ошибке;
- посты/акции лениво (`loading="lazy"`), hero — приоритетно;
- пустые блоки просто не рендерятся, поэтому у продавцов без контента страница остаётся такой же быстрой;
- цвета — через токены дизайн-системы, тёмная секция на существующих brand-токенах;
- SEO: сохраняются текущие `SEO`-теги, девиз попадает в description, prerender продолжает работать.
