# /seller/story: галерея шаблонов и второй шаблон «О продукте»

## Что увидит продавец

### 1. Галерея шаблонов (новый первый экран `/seller/story`)
- Заголовок «Создать изображение», ниже две крупные карточки-превью шаблонов (9:16, статичные мини-макеты в стиле холста):
  - **«В наличии»** — до 4 товаров, цена и срок (существующий шаблон).
  - **«О продукте»** — до 2 товаров, фото, описание, рейтинг.
- Нажатие открывает редактор выбранного шаблона по адресу `/seller/story/stock` или `/seller/story/about` (стабильные ссылки для Telegram-бота).
- В редакторе переключателя нет: кнопка «Назад» ведёт обратно в галерею.

### 2. Редактор «В наличии»
Без изменений (список товаров до 4, фоны, заголовок, превью, Скачать/Поделиться). Просто переезжает на `/seller/story/stock`.

### 3. Редактор «О продукте» (`/seller/story/about`)
Те же блоки настроек, что и в первом шаблоне, плюс отличия:
- **Товары**: чекбоксы, максимум 2 («Выбрано N из 2»).
- **Фон**: та же галерея готовых фонов + «Загрузить своё» с обрезкой 9:16 (переиспользуется `BackgroundPicker`).
- **Вид карточки** (тема A / B, сегмент из двух вкладок с мини-иконками):
  - **A — «Фото сверху»**: белая карточка, фото 1:1 со скруглением сверху, под ним тёмный текст.
  - **B — «Фото на всю карточку»**: фото заполняет карточку целиком, снизу вверх плавный тёмный градиент (`from-black/75 via-black/25 to-black/10`, как в hero страницы продавца), текст светлый поверх градиента.
- **Галочка «Показывать рейтинг»** — включена по умолчанию.
- Кнопки «Скачать» / «Поделиться» — те же, что сейчас (общая логика экспорта).

### 4. Холст «О продукте» (1080×1920)
- Фон на всю площадь (готовый или свой).
- Карточки по центру: 1 товар — одна крупная карточка (~900px шириной); 2 товара — две карточки в ряд (~500px каждая, шрифты пропорционально меньше).
- Внутри карточки:
  - Название — крупно, жирно (до 2 строк, многоточие).
  - Описание из поля товара — 2 строки максимум, обрезка с многоточием.
  - Строка статистики из 3 блоков с тонкими разделителями: **★ 4.8 / Рейтинг** | **12,50 BYN / Цена** | **250 г / Порция** (подпись «Порция», значение — единица измерения товара).
  - Если рейтинг выключен галочкой **или** у товара нет отзывов — блок рейтинга скрыт, остаются два блока по центру.
  - Если у товара нет единицы измерения — блок «Порция» скрыт.
- Пилюли-кнопки нет. Нижняя стеклянная плашка «Переходите на сайт и заказывайте, ссылка в шапке профиля» — как в первом шаблоне.
- Шрифт — Manrope (уже подключён на странице).

## Технические детали

- **Роуты** (`src/App.tsx`, lazy):
  - `/seller/story` → `src/pages/seller/SellerStoryGallery.tsx` (галерея).
  - `/seller/story/stock` → существующий `SellerStory.tsx` (переименовать в `SellerStoryStock.tsx`; «Назад» → `/seller/story`).
  - `/seller/story/about` → новый `src/pages/seller/SellerStoryAbout.tsx`.
  - Ссылка из `SellerDashboard.tsx` остаётся на `/seller/story`.
- **Общий код** выносится из `SellerStory.tsx`, чтобы не дублировать:
  - `src/hooks/useStoryProducts.ts` — загрузка активных товаров продавца (добавляется поле `description`) и проверка роли.
  - `src/hooks/useStoryExport.ts` — `renderPng` / `handleDownload` / `handleShare` / состояние `exporting` (modern-screenshot, ожидание шрифтов и картинок).
  - `src/components/seller/story/StoryEditorLayout.tsx` — обёртка редактора: шапка с «Назад», масштабируемое превью (45svh на мобильном, sticky на десктопе), фиксированная нижняя панель кнопок. Принимает `children` (секции настроек) и `canvas`.
  - Секции «Товары» (с параметром `max`) и «Фон» становятся переиспользуемыми компонентами (`StoryProductPicker.tsx`).
- **Новые компоненты холста**:
  - `src/components/seller/story/AboutStoryCanvas.tsx` — фон, сетка 1–2 карточек, нижняя плашка.
  - `src/components/seller/story/AboutProductCard.tsx` — карточка с пропсами `theme: "photoTop" | "photoFull"`, `size: "lg" | "md"`, `rating?: { avg: number; count: number }`, `showRating`. Строка статистики с разделителями; звезда — inline SVG (иконки lucide `Star`), значение рейтинга с одной десятичной (`4.8`), цена через `formatPrice` + `BynSymbol`.
  - `src/components/seller/story/StoryTemplateCard.tsx` — карточка-превью шаблона для галереи (мини-макет CSS, без картинок).
- **Рейтинг**: `src/hooks/useProductRatings.ts` — один запрос `reviews.select("product_id, rating").in("product_id", ids)` для выбранных товаров, агрегирование в `Map<productId, {avg, count}>`.
- **Загрузка фото для экспорта**: как и сейчас — оригинал из Storage с `crossOrigin="anonymous"`; для темы B картинка через `object-fit: cover` на всю карточку, поверх — `div` с linear-gradient (modern-screenshot корректно рендерит градиенты).
- Новых таблиц, миграций и зависимостей не требуется.
